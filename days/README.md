## 每天打印建议

每张纸上应该只有**一天**。打印前在页眉写上当天的日期，学完直接在纸上勾最上面那三个方框：

```
□ 所有命令都跑通了   □ 今日自查能答出   □ 写下一行"我原来想错的地方"
```

## 三天一循环的检查点
